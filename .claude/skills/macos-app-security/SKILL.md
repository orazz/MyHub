# Security in MyHub

## Secrets
- Store secrets **only in Keychain**, as `kSecClassGenericPassword`, service `com.orazz.myhub.credentials`, account = provider id, `kSecAttrAccessible = kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, `kSecAttrSynchronizable = false`.
- `preferences.json` holds a `SecretRef` (id) only. It never holds the key, a token, or a prefix longer than 4 chars.
- Wrap in-memory secrets in `Redacted<String>` (`description` → `"••••1234"`). Don't put a secret in string interpolation, `print`, `Logger`, error messages, or crash-visible `fatalError` text.
- Pass secrets into a `SecureField`, then straight into Keychain. Don't echo them back; show last 4 chars only.
- Delete the Keychain item when the provider is removed.

## Third-party credentials (read-only, opt-in)
| Source | Access |
|---|---|
| Claude Code OAuth | Keychain generic password, service `Claude Code-credentials` → JSON `claudeAiOauth.accessToken` / `expiresAt`. The system shows an access prompt, so explain it first. |
| Codex / ChatGPT | `~/.codex/auth.json` → `tokens.access_token`, `tokens.account_id` |
| AWS | `~/.aws/credentials` / `~/.aws/config` named profile (static keys v1) |
- Only after the user enables that provider and presses a button.
- Re-read on each fetch. Never cache to disk, never copy into our Keychain, never refresh or write back (that would race the owning tool's refresh and could invalidate its session).
- If the token has expired, show "Open Claude Code / Codex to refresh sign-in".

## Network
- Use `URLSession(configuration: .ephemeral)`, with `httpCookieStorage = nil`, `urlCache = nil`, `urlCredentialStorage = nil`, and a 20 s timeout.
- HTTPS only. The custom endpoint may use `http` only for `localhost`/`127.0.0.1`/`::1`.
- Each provider declares an **allowed host set**. `HTTPClient` rejects requests to any other host.
- Redirects: implement `urlSession(_:task:willPerformHTTPRedirection:newRequest:)` and return `nil` if the host changes. Never forward `Authorization`/`x-api-key` across hosts.
- Cap response size (4 MB) and reject non-JSON content types for JSON endpoints.
- Respect `429` + `Retry-After`. Use exponential backoff with jitter, capped at 30 min.
- Log only method, host, path and status, with query strings stripped (they may contain ids).

## Untrusted input
- **Clipboard:** skip anything with `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType`, and anything copied while the frontmost app is excluded (password managers). Keep history in memory by default. Persisted history is AES-GCM (`CryptoKit`) with the key in Keychain.
- **Calendar events:** anyone can send an invite. Show a Join button only for `https` URLs on an allowlisted meeting host, and re-validate on click.
- **API/log JSON:** `Decodable` with optional fields and defaults. Never force-unwrap or `try!`. Bound array sizes and string lengths shown in the UI.
- Opening URLs: `NSWorkspace.open` only after a scheme check (`https`, or `file` for stash items). Never build shell commands or AppleScript from data.

## Running tools (git, simctl, shortcuts)
- Always `CommandRunner.run(absolutePath, [arguments])`. Never `/bin/sh -c`, never string-built command lines, never a `PATH` lookup.
- Validate anything user-typed that becomes an argument. A value that could start with `-` must not reach a tool as a flag (UDIDs are pattern-checked, bundle IDs too).
- Check `CommandRunner.developerToolsInstalled()` before `/usr/bin/git` or `xcrun`. Without Xcode or the CLT those shims pop up an install dialog.
- Deleting files goes only through `CleanupTarget`, which removes **children** of known folders under `~/Library`, with a two-step confirm in the UI. Archives go to the Trash.

## GitHub
- `GitHubClient` uses `HTTPClient(allowedHosts: ["api.github.com"])`. Its token is optional, kept in the Keychain (account `github`), and read per request.
- Links from API responses are opened only via `GitHubDecoding.safeWebURL` (`https://github.com/…`).

## Microsoft 365 (Graph)
- Public-client OAuth: authorization code + PKCE (S256) in the default browser, `state` checked, the reply caught by `LoopbackRedirect`, which listens on the **loopback interface only**, answers one request, and stops (5-minute limit). No client secret exists or may be added.
- Scopes are exactly `offline_access User.Read Calendars.Read`. The refresh token lives in the Keychain (`microsoft.refresh`) and access tokens in memory only. A 400 on refresh means `.expired`, so the user must sign in again.
- `HTTPClient` allow-list: `login.microsoftonline.com`, `graph.microsoft.com`. Paging links are followed only if they're Graph's own. Join URLs pass `CallLinkDetector.isJoinable`.

## Agent hooks
- `AgentHookServer` listens on the **loopback interface only**. Every request needs the `X-MyHub-Token` header, compared in constant time. That stops web pages from posting fake events to localhost.
- Requests: bodies are capped at 1 MB and chunked encoding is refused. Each connection lives at most 5 seconds, and the reply is always an immediate `{}`.
- Payloads are untrusted. `AgentEvent` clips every string. Prompts and commands stay in memory only, are never written to disk, and are maskable by the Privacy Shield.
- The installed hook is `curl … || true` with `async: true`. It must never block or fail the agent.
- **Approvals** (`/permission/<agent>`):
  - Opt-in, and Claude Code only. Nothing is decided without a click on Allow or Deny.
  - Timeout, dismissing, MyHub not running, or approvals switched off all mean "no decision" (`{}`), and the agent shows its own prompt.
  - `PermissionAnswer` sends once.
  - Never add auto-allow rules.
- Editing agents' settings files goes only through `AgentHookInstaller`: it keeps a backup, never writes invalid JSON, and touches only its own entries.

## Jira
- Sites must be `<name>.atlassian.net` (`JiraSite`). The email+API token pair is sent only to that host (`HTTPClient` allow-list) as Basic auth. The token lives in the Keychain (account `jira`) and is stored only after `/myself` accepts it.
- Issue keys from responses are pattern-checked (`JiraClient.isIssueKey`) before they go into a URL path. Links are opened only if `JiraSite.owns(url)`.

## Figma
- Personal access token in the Keychain (`figma`), sent only as `X-Figma-Token` to `api.figma.com`; no redirects.
- File keys, node ids and comment ids are validated before they reach a URL; inbox items open only `https://www.figma.com`.
- Comment text is untrusted: one line, clipped, never rendered as Markdown or HTML.
- Rate limits are per seat (View: 5/min on comments and versions): check at most every 5 min, honour `Retry-After`.

## Files
- `~/Library/Application Support/MyHub/` gets 0700. Files are written with `.atomic`, then `FileManager.setAttributes([.posixPermissions: 0o600])`.
- Never overwrite a file that failed to parse. Mark it broken and stop writing so user edits are preserved.

## Build / distribution
- Hardened runtime, Developer ID signing, notarization, `codesign --verify --strict`.
- Entitlements are minimal: `com.apple.security.personal-information.calendars`. Add others only with a comment explaining which feature needs them.
- Info.plist usage strings: `NSCalendarsFullAccessUsageDescription`.
- No third-party packages. Adding one needs an explicit decision in `docs/PLAN.md`.
